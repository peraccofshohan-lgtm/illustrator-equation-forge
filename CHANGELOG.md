# Changelog

## 0.1.0 — 2026-11-21 — Development pre-release

- Added ES3-oriented standalone core with tokenizer, precedence parser, recursive AST helpers, validation limits, symbol command lookup, and safe syntax serialization.
- Added ScriptUI typing dialog, basic symbol search, editable built-in expression examples, syntax file save/open, bounded editor undo/redo, and approximate Illustrator-native text/path insertion code.
- Added deterministic standalone JSX build and Node-based core regression tests.
- Documented compatibility and extensive unimplemented areas. No production release claim; Illustrator runtime testing remains pending.
