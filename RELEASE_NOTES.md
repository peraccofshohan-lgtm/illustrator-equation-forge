# Release notes — 0.1.0 development pre-release

This is an early engineering build for evaluation, not a production release. It provides a limited typed-expression workflow, a small symbol index, example insertion templates, `.eqforge` syntax save/open, and an approximate Illustrator insertion adapter.

The product has not been executed inside Adobe Illustrator in the available environment. No Illustrator version is certified. Typography is approximate and major requested subsystems remain unimplemented; consult `KNOWN_LIMITATIONS.md` before use. No GitHub release or production tag is being issued from this state.
